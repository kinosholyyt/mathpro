# MathPro

Математиканы репетитормен үйрететін интерактивті платформа.

**Дайын бөлімдер:** оқушы аккаунттары (кіру және тіркелу), басты бет, сабақтар (видео, теория, талданған мысал, тексеру сұрағы), әкімші панелі.

**Жоспарда:** есептер, тест орталығы, ойындар, формулалар, «Менің нәтижем», күн тапсырмасы.

**Технологиялар:** HTML, CSS, JavaScript (кітапханасыз). Аккаунттар, прогресс және сабақтар Firebase-те сақталады.
