# MathPro

Математиканы репетитормен үйрететін интерактивті платформа.

**Бөлімдер:** сабақтар (видео, теория, талданған мысал, тексеру сұрағы), есептер (жауапты тексеру, кеңес, шешу жолы), тест орталығы (таймермен), ойындар, формулалар жинағы, «Менің нәтижем», күн тапсырмасы, оқушы аккаунттары және әкімші панелі.

**Технологиялар:** HTML, CSS, JavaScript (кітапханасыз). Деректер браузердің жадында (localStorage) сақталады.
